# [Week 1] Data + Errors: entities, DTOs and global exception handler
**Branch:** `feature/data-entities`

**Goal:** the relational model for documents and chat history, plus consistent error responses.

## Tasks
- [ ] Entities: `DocumentRecord` (id UUID, filename, contentType, sizeBytes, status enum, chunkCount, uploadedBy, uploadedAt), `ChatSession`, `ChatMessage` (role USER/ASSISTANT, content, createdAt, LAZY ManyToOne to session). Reference the user by id, not by an association, so you are not blocked on the Security entity.
- [ ] Repositories for all three.
- [ ] DTO Records + mapping for each (entities never go to the client).
- [ ] `GlobalExceptionHandler` with `@RestControllerAdvice` returning RFC 7807 `ProblemDetail`: validation errors (400), `ResourceNotFoundException` (404), generic (500).
- [ ] Repository tests with Testcontainers (reuse the Lead's base class, or a temporary one).

## Done when
Tables are generated by Hibernate, repositories pass tests, and a bad request returns a clean ProblemDetail JSON.
