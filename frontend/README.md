# Frontend

React app (functional components, Axios/Fetch). Owned by the Frontend role.

Scaffold it here in Week 1 (`npm create vite@latest . -- --template react`, or the TypeScript template if preferred). CI builds this folder automatically once `package.json` exists, so commit `package-lock.json` too.

Dev tip: proxy `/api` to `http://localhost:8080` in `vite.config` so you do not need CORS while developing.
